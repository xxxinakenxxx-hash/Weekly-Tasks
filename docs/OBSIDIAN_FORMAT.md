## 共通
- 1行目：`# 通常業務` または `# AI案件`
- 冒頭に `対象週：yyyy-MM-dd（月）〜yyyy-MM-dd（日）` と `確認日：yyyy-MM-dd` を書く
- 1件ごとに `## 番号. 件名` の見出しを置き、その下に `- 項目：内容` を並べる
- 取得できない・判断できない内容は推測で埋めず「要確認」と書く

## 通常業務.md（Web版Work）
```
# 通常業務

対象週：2026-09-28（月）〜2026-10-04（日）
確認日：2026-10-01

## 1. 件名
- 情報源：
- 対応候補：
- 期限：（取得不能は「要確認」）
- 関係案件：
- 依頼内容：
- 会議・予定との関係：
- 要確認事項：
```

## AI案件.md（デスクトップ版Work）
```
# AI案件

対象週：2026-09-28（月）〜2026-10-04（日）
確認日：2026-10-01
巡回フォルダ：C:\Users\inamori240\Documents

## 1. 案件名
- 現在工程：
- 工程状態：途中／完了
- 完了内容：
- 残事項：
- 次回開始位置：現工程の続き／次工程
- 次にやる具体作業：
- 現在の手番：
- 情報源整合：一致／不一致／要確認
- 要確認：（判断不能な例外のみ。なければ「なし」）
- 参照した情報源：
  - TASK_CURRENT.md：（ファイルの場所。見つからない場合は「なし」）
  - Drive：（正本・開発工程表・実装指示書・関連資料のファイル名）
  - Codexチャット：（スレッド名。特定できない場合は「チャット未確認」）
- 不一致の内容：（情報源整合が「不一致」の場合だけ、どの情報源で何が違うか）
```
