# Web版Work 毎朝の指示文（当日情報 → 朝情報.md）

毎朝、Web版Workへ次をそのまま送る。Gmail・Googleカレンダー・Google Driveは会社アカウントで接続する。
日次経路ではObsidian（「週間タスク」フォルダ）を使わない。

```
今日の朝ブリーフ用の当日情報を収集し、Google Drive「週間タスクボード」フォルダ直下の「朝情報.md」へ保存してください（既存ファイルがあれば上書き）。
「週間タスク」フォルダ（Obsidian Vault）には保存しない・読まないでください。

対象：今日の Googleカレンダーの予定、Gmail の要対応メール（昨日以降に届いたもの）、今日に関係する Google Drive 上の資料。
次の書式で書いてください。

# 朝情報

日付：（今日 yyyy-MM-dd）
取得日時：（yyyy-MM-dd HH:mm）

## 今日の予定
- HH:mm〜HH:mm 件名（場所）

## 要対応メール
- 件名／送信者／要点／期限（不明は「要確認」）

## 関係する資料
- ファイル名／要点

## 取得できなかった情報
- （取得に失敗した情報源があれば「取得失敗：情報源名」。なければ「なし」）

ルール：
- 推測で埋めない。判断できない点は「要確認」と書く。
- 保存後、ファイル名・保存先・予定件数・要対応メール件数を報告する。
```
