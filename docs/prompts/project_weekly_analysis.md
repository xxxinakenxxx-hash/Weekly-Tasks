# ChatGPT Project 週間分析 指示文（→ 週間画面へ貼り付けるJSON）

Web版Work・デスクトップ版Workの保存が終わったあと、ChatGPT Project の新しいチャットへ次を送る（ユーザーの一言入力が開始契機）。Google Driveは会社アカウントで接続する。
出力形式は docs/HANDOFF_FORMAT.md。

```
今週の週間分析をしてください。次を実際に開いて読み、推測で答えないでください。
- Google Drive「週間タスクボード」フォルダ内「週間タスク」フォルダ直下の「通常業務.md」「AI案件.md」
- スプレッドシート「週間タスクボード」の「タスク」シート（対象週と前週までの確定タスク・状態・実施結果・メモ・次回申し送り）

結果は次のJSON形式「だけ」で出力してください。説明文やコードブロック記号（```）は付けないでください。

{
  "対象週": "（今週の月曜 yyyy-MM-dd）",
  "見立て": "今週は何が中心の週か、負荷の偏り、前週からの未完了・持越しの状況（文章）",
  "コーション": ["期限接近・停滞・次工程不明・要確認などの注意", "..."],
  "タスク案": [
    {"タスク名": "...", "種別": "通常タスク", "曜日": "木", "優先度": 1, "重点": true, "例外情報": ""},
    {"タスク名": "...", "種別": "AI案件", "曜日": "", "優先度": 2, "重点": false, "例外情報": "", "AI案件現在地": "現在工程・工程状態・次にやる具体作業・現在の手番の要約"}
  ]
}

ルール：
- 「種別」は 通常タスク または AI案件。AI案件.md の案件は AI案件、通常業務.md の事項は 通常タスク。
- 「曜日」は 月・火・水・木・金 のどれか。複数日に分けて取り組む場合は ["月","火","水"] のように配列で書く（1タスクは1件のまま。曜日ごとに同じタスクを複製しない）。決められない場合は空文字 ""。
- 「優先度」は1以上の整数（1が最優先）。「重点」は true／false（今週の重点は3〜5件が目安）。
- 「例外情報」は通常は空文字 ""。区分：内容 の形で、区分は 要確認／不一致／チャット未確認／取得失敗 のみ。
  AI案件.md で「情報源整合：不一致」の案件は「不一致：内容」、「チャット未確認」の案件は「チャット未確認：内容」をそのまま引き継ぐ。
- 「AI案件現在地」は 種別がAI案件 の場合だけ書く。
- 「タスク」シートで対象週（今週の月曜）の行は、すでに確定済みのタスク。これと同じタスクはタスク案に出さない（新規候補として再生成しない）。
  その状態・実施結果・メモ・次回申し送りは、見立て・コーションで触れてよい。
- 前週以前の行で状態が 次週候補・持越し・未着手・進行中 のものは、見立て・コーションで触れる。今週のタスク案に含める場合は、対象週に同じタスク名の行がすでにないことを確認してから出す（ある場合は出さない）。
- 期限・担当・次工程などを推測で埋めない。読めなかったファイルがある場合は、コーションに「取得失敗：ファイル名」と書く。
```
