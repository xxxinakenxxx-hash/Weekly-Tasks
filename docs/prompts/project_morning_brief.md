# ChatGPT Project 朝ブリーフ 指示文（→ 朝ブリーフ画面へ貼り付けるJSON）

Web版Workの `朝情報.md` 保存後、ChatGPT Project の新しいチャットへ次を送る。Google Driveは会社アカウントで接続する。
出力形式は docs/BRIEF_FORMAT.md。日次経路ではObsidianを使わない。

```
今日の朝ブリーフを作ってください。次を実際に開いて読み、推測で答えないでください。
- Google Drive「週間タスクボード」フォルダ直下の「朝情報.md」
- スプレッドシート「週間タスクボード」の「タスク」シートのうち、今週（対象週＝今週の月曜）の行（タスク名・種別・曜日・状態・優先度・重点・実施結果・メモ・次回申し送り・例外情報・AI案件現在地）
「週間タスク」フォルダ（Obsidian Vault）の「通常業務.md」「AI案件.md」は読まないでください。

結果は次のJSON形式「だけ」で出力してください。説明文やコードブロック記号（```）は付けないでください。

{
  "日付": "（今日 yyyy-MM-dd）",
  "今日の一言": "今日はどんな一日か（短い見立て）",
  "今日の流れ": ["HH:mm 予定", "..."],
  "今日優先すること": ["今日の曜日に配置されたタスク・要対応メールのうち優先するもの", "..."],
  "気にかけておきたいこと": ["期限接近・要確認・不一致など", "..."],
  "もう片づいていること": ["今週のタスクで状態が完了のもの", "..."],
  "未完了・持越し": ["今週のタスクで未着手・進行中のまま気にすべきもの、状態が持越し・次週候補のもの", "..."]
}

ルール：
- 項目が無い場合は空配列 [] にする。
- 「今日の流れ」は朝情報.md の今日の予定を時刻順に並べる。
- タスクの状態は「タスク」シートの値をそのまま使い、推測で変えない。
- 例外情報（要確認・不一致・チャット未確認・取得失敗）があるタスクは「気にかけておきたいこと」に区分ごと書く。
- 朝情報.md に「取得失敗」がある場合、または朝情報.md・タスクシートを読めなかった場合は、「気にかけておきたいこと」に「取得失敗：内容」と書く。
```
