# 追加改修指示書 — 指示ルート（指示元 → 実装先）の追加

週間タスク・朝ブリーフ　追加改修指示書 v1.0（2026-10-09 ユーザー指示「④指示ルート」）

> 位置づけ：IS-00〜IS-06、追加実装指示書 v1.2、追加改修「保留」v1.0 とは別の独立した追加改修とする。IS-06 総合試験・受入は継続中のまま（完了扱いにしない）。既存データ・履歴・機能、および「保留」の実装を維持する。

## 0. 正本との関係（仕様変更記録）

- 正本 v1.7 のデータ設計書に「指示元・実装先」の項目はない。本改修で「タスク」シートに2列（指示元・実装先）を追加する。
- 正本4点は書き換えない。正本との差分は本書と docs/DB_SCHEMA.md で管理する。

## 1. 目的

各AI案件のカードを見れば、誰に実装指示を依頼すればよいか一目で分かるようにする。

## 2. 仕様

- 「指示元 → 実装先」の形式で表示する（例：`Claude → Codex`、`ChatGPT → Claude Code`）。
- AI案件ごとに指示元・実装先を個別に設定できる。
- 週間タスクのカードに常時表示し、編集・保存・再読込できる。
- Google Sheetsに保存し、翌週へ引き継ぐ。
- 未登録の場合は「未設定」と表示する。推測で補完しない。
- 通常タスクには原則表示しない。

## 3. 実装上の扱い（2026-10-09 実装時）

- 保存先：「タスク」シートの末尾に「指示元」（16列目）「実装先」（17列目）を追加する。既存の15列のシートは、読み書き時に見出しのセルだけを書き足す（既存の値・行は変えない）。入力規則は付けない（自由記入）。
- 表示：AI案件のカードに「指示ルート：指示元 → 実装先」を常時表示する。両方空欄は「指示ルート：未設定」、片方だけ空欄はその側を「未設定」と表示する。
- 編集：AI案件の「詳細・編集」に指示元・実装先の入力欄を置き、「確定して保存」で保存する。履歴は「修正／指示元」「修正／実装先」（変更前後）。
- 通常タスク：表示せず、入力欄も出さない。サーバー側でも通常タスクへの設定は拒否する。
- 翌週への引継ぎ：「前週の次週候補・持越しを取り込む」で、指示元・実装先も翌週の新しい行へコピーする。「保留」は従来どおり取り込み対象外。
- 対象外（今回は変更しない）：朝ブリーフ画面の表示、手動タスク追加の入力欄。

## 3B. 入力方式（2026-10-09 追加指示）

- 「指示元」「実装先」を自由入力からドロップダウンに変更する。
- 両方の選択肢：ChatGPT／Claude／Claude Code／Codex／Gemini／その他／未設定。
- 「その他」を選んだ場合のみ自由入力できる。
- 既存の保存値・変更履歴・案件キー・翌週への引継ぎ処理は維持する。
- 実装上の扱い：「未設定」は空欄として保存する。「その他」を選んだだけでは値を変えず、入力したときに保存対象になる（「その他」に選択肢と同じ名前を入れた場合はその選択肢として扱う）。選択肢にない既存の保存値は「その他」＋その値として表示し、値は変えない。Sheetsの列に入力規則は付けない（「その他」の自由入力があるため）。

## 3A. 継続処理（2026-10-09 追加指示）

### 要件
- 指示ルートは週単位ではなくAI案件単位で保持する。
- 翌週の週間分析で同じ案件が新規作成されても、前回の指示元・実装先を引き継ぐ。
- ユーザーが明示的に変更した場合のみ更新する。
- 案件の誤対応を防ぐ識別方法を設ける。特定できない場合は推測しない。
- 既存データ・履歴を維持する。

### 実装上の扱い
- 識別方法：「タスク」シート18列目に「案件キー」を追加する。値は AI案件.md に記載された、その案件の TASK_CURRENT.md の場所（例：`C:\Users\inamori240\Documents\営業AIメモ\tasks\TASK_CURRENT.md`）。案件ごとのリポジトリに1つずつあるため、案件の識別に使う。タスク名では突き合わせない。
- 値の制限：末尾が TASK_CURRENT.md の文字列だけ。AI案件だけ。対象週の中で同じ案件キーのAI案件は1件だけ（取り違え防止）。比較は前後の空白・「/」「\」・大文字小文字の違いを同じとみなす。
- 週間分析：ChatGPT Project の指示文（docs/prompts/project_weekly_analysis.md）と受け渡し形式（docs/HANDOFF_FORMAT.md）に任意の「案件キー」を加える。AI案件.md の場所を一字も変えずに書き、分からない場合は書かない。
- 引継ぎ：新しく作るAI案件に案件キーがあり、指示元・実装先とも空欄なら、対象週より前の週で同じ案件キーのいちばん新しい週の行（削除済みを除く）の指示元・実装先を入れる。週間画面では候補の段階で「（yyyy-MM-dd の週から引継ぎ）」と表示し、「確定して保存」で保存する。
- 引き継がない場合（「未設定」のまま）：案件キーが無い、前の週に同じ案件キーが無い、その週に同じ案件キーで指示ルートが食い違う行がある。最新の週で空欄に戻されている場合は空欄を引き継ぐ（古い値を復活させない）。
- 更新：指示ルートが変わるのは、ユーザーが「詳細・編集」で変更して保存したときだけ。前後の週の行は自動で変えない。案件キーを後から設定しても指示ルートは自動で変えない。
- 既存行：今ある行の案件キーは空欄のまま。ユーザーが「詳細・編集」で設定するか、次回以降の週間分析で案件キーつきで作られた行から引継ぎが始まる。
- 持越し・次週候補の取り込みでは、案件キーも翌週の新しい行へ引き継ぐ。
