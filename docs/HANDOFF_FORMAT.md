# ChatGPT Project 分析結果の受け渡し形式（IS-00 PoC4）

## 方式（2026-10-01 ユーザー決定）
貼り付け方式。ChatGPT Projectが下記JSONを出力し、ユーザーがコピーして週間画面の入力欄へ貼り付ける。
画面はその場で読み込んで表示するだけで、確定するまでどこにも保存しない（候補専用の保存領域・仮テーブルを作らない）。

## JSON形式
```json
{
  "対象週": "2026-09-28",
  "見立て": "今週の見立て（文章）",
  "コーション": ["注意・コーション1", "注意・コーション2"],
  "タスク案": [
    {
      "タスク名": "勤怠の確認・月次提出",
      "種別": "通常タスク",
      "曜日": "木",
      "優先度": 1,
      "重点": true,
      "例外情報": ""
    }
  ]
}
```

| キー | 必須 | 値 |
|---|---|---|
| 対象週 | 必須 | その週の月曜日 `yyyy-MM-dd` |
| 見立て | 必須 | 文字列（出力2 今週の見立て） |
| コーション | 必須 | 文字列の配列（出力3 注意・コーション） |
| タスク案 | 必須 | 配列（出力1 週間タスク案、出力4 優先順位案・曜日配置案） |
| タスク案[].タスク名 | 必須 | 文字列 |
| タスク案[].種別 | 必須 | 通常タスク／AI案件 |
| タスク案[].曜日 | 任意 | 月／火／水／木／金／空欄 |
| タスク案[].優先度 | 任意 | 1以上の整数（1が最優先） |
| タスク案[].重点 | 任意 | true／false |
| タスク案[].例外情報 | 任意 | 「区分：内容」。区分は 要確認／不一致／チャット未確認／取得失敗 |

値は DB_SCHEMA（docs/DB_SCHEMA.md）の選択肢と同じ。形式に合わない場合、画面はエラー枠に理由を表示し、何も表示しない。
