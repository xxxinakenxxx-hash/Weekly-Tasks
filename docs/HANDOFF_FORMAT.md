# ChatGPT Project 分析結果の受け渡し形式（IS-00 PoC4）

## 方式（2026-10-01 ユーザー決定）
貼り付け方式。ChatGPT Projectが下記JSONを出力し、ユーザーがコピーして週間画面の入力欄へ貼り付ける。
画面は読み込んだタスク案を「候補」として週間ボードへ直接表示する。確定するまでどこにも保存しない（候補専用の保存領域・仮テーブルを作らない）。
ユーザーが週間画面で採用/削除・修正し、「確定して保存」を1回押すと、残った候補を正データへ保存する（IS-01）。
「見立て」「コーション」は表示のみで保存しない。
対象週の保存済みタスクとタスク名が完全一致するタスク案は候補にせず、「既存タスクと同名のため候補から除外：N件（名前）」と表示する（類似判定はしない）。保存時もサーバー側で、対象週＋タスク名の完全一致による重複追加・重複名への変更を拒否する（IS-02）。分析結果の「対象週」が表示中の週と違う場合は読み込まない。

## JSON形式
```json
{
  "対象週": "2026-09-28",
  "見立て": "今週の見立て（文章）",
  "コーション": ["注意・コーション1", "注意・コーション2"],
  "タスク案": [
    {
      "タスク名": "勤怠の確認・月次提出",
      "種別": "通常タスク",
      "曜日": "木",
      "優先度": 1,
      "重点": true,
      "例外情報": ""
    },
    {
      "タスク名": "週間タスク・朝ブリーフ",
      "種別": "AI案件",
      "曜日": "",
      "優先度": 2,
      "重点": true,
      "例外情報": "不一致：TASK_CURRENT.mdとDriveの工程が異なる",
      "AI案件現在地": "IS-02 途中／次：AI案件巡回の実施／手番：ユーザー"
    }
  ]
}
```

| キー | 必須 | 値 |
|---|---|---|
| 対象週 | 必須 | その週の月曜日 `yyyy-MM-dd` |
| 見立て | 必須 | 文字列（出力2 今週の見立て） |
| コーション | 必須 | 文字列の配列（出力3 注意・コーション） |
| タスク案 | 必須 | 配列（出力1 週間タスク案、出力4 優先順位案・曜日配置案） |
| タスク案[].タスク名 | 必須 | 文字列 |
| タスク案[].種別 | 必須 | 通常タスク／AI案件 |
| タスク案[].曜日 | 任意 | 月／火／水／木／金／空欄 |
| タスク案[].優先度 | 任意 | 1以上の整数（1が最優先） |
| タスク案[].重点 | 任意 | true／false |
| タスク案[].例外情報 | 任意 | 「区分：内容」。区分は 要確認／不一致／チャット未確認／取得失敗。複数は「／」でつなぐ。不一致・チャット未確認を含む案は、週間画面でカードの確認チェックを入れないと保存できない（IS-05） |
| タスク案[].AI案件現在地 | 任意 | 文字列。種別＝AI案件のときだけ（IS-02で追加）。Sheets「AI案件現在地」列へ保存 |

値は DB_SCHEMA（docs/DB_SCHEMA.md）の選択肢と同じ。形式に合わない場合、画面はエラー枠に理由を表示し、何も表示しない。
