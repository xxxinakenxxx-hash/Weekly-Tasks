# Workの自動実行設定（追加実装 v1.1）

根拠：docs/implementation/追加実装指示書_複数日配置・日次AI現在地連携・手動タスク追加_v1.2.md §3。

- 設定場所・設定方法・実行時刻は、実機で確認・設定した結果だけを記入する。推測で記入しない。
- 実機で自動実行を設定できない場合は、代替手段を採らずに停止して報告する。
- 設定結果は `tasks/TASK_CURRENT.md` にも「設定済み／未設定」と実行条件を記録する。

## 実行順序（確定事項）
- 週次：Web版Workの通常業務週次収集 ＋ Desktop版WorkのAI案件週次巡回 → ChatGPT Project（週間分析）→ 週間タスクJSON → 週間タスク画面
- 日次朝：Web版Workの朝情報収集 ＋ Desktop版WorkのAI案件日次現在地巡回 → ChatGPT Project（朝ブリーフJSON 1本）→ 朝ブリーフ画面で読込・保存
- 各Workの収集は、ChatGPT Projectで JSON を作る時刻までに完了させる。

## 予約名のルール（2026-10-09 決定）
- 週間タスク・朝ブリーフで使う予約は、名前の先頭に必ず【週間タスク】を付ける：【週間タスク】週次AI巡回／【週間タスク】日次AI現在地巡回／【週間タスク】朝情報収集
- 試験用の予約は【週間タスク・試験】で始め、試験が終わったら必ず削除する
- 週間タスク・朝ブリーフの会話（チャット）と予約は、必ずプロジェクト「週間タスク」の中で作る。依頼文の1行目に【週間タスク】で始まる名前を書き、チャット名もその名前にする。プロジェクトの外にできた関係の会話は、どこにも属さないチャットとして扱い、削除の対象にする
- 2026-10-12：プロジェクト「週間タスク」から Documents（営業AIメモの TASK_CURRENT.md 先頭3行）を読めることを確かめ、週次・日次の予約をプロジェクト「週間タスク」へ移した
- 予約を作る・差し替える依頼文には、必ず名前を書く（名前なしで作らない。名前なしだと指示文の書き出しが名前になり、見分けられなくなる）
- サイドバーには予約とチャットが混ざって並ぶ。時計の印が付いているものだけが予約から動いたチャット
- 現在の名前（2026-10-12）：【週間タスク】週次AI巡回／【週間タスク】日次AI現在地巡回（変更済み）。Web版の朝情報収集は「今日の朝ブリーフ用の当日情報を収集し、Googl…」のまま（未変更）
