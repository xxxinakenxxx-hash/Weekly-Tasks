週間タスク・朝ブリーフ ユーザー操作マニュアル

この手順で、週のタスクを登録し、平日の朝ブリーフを保存します。ChatGPT に貼る文は、このページの付録A〜Fの「コピー」ボタンでコピーしてください（付録の文は、いつも最新のものです）。

実施するタイミング

いつあなたがすること
毎週月曜 5:45Desktop版WorkのAI案件の週次巡回は自動です。何もしません。
毎週月曜、業務開始後「毎週月曜に行う操作」の1〜4を行います。
平日 6:15・6:30 の自動処理後Desktop版Work（AI案件の日次巡回）とWeb版Work（朝情報）は自動です。そのあと「毎朝に行う操作」の1〜3を行います。

画面表示や通知で自動処理が失敗したと分かった場合は、JSONの作成・保存へ進まず、そのままの状態で連絡してください。

毎週月曜に行う操作

1. Web版Workで通常業務を集める

ブラウザで https://chatgpt.com/ を開き、Web版Workを選んで新しいチャットを開きます。付録Aをコピーして貼り付け、送信します。

2. 週間タスクのJSONを作る

ChatGPT のプロジェクト「週間タスク」で新しいチャットを作ります。付録Bをコピーして貼り付け、送信します。返ってきた JSON（{ から } まで）を全部コピーします。

3. 週間タスク画面へ読み込む

週間タスク画面を開き、「ChatGPT Project の分析結果を読み込む」を開きます。JSONを貼り付けて「読み込む」を押します。

4. 内容を確認して保存する

  • 新しいタスクは「候補」として出ます。
  • 今週の表にすでにあるAI案件は「分析結果で更新」と出ます。保存すると、現在地と例外情報が新しい内容に変わります（内容が同じなら「内容に変わりなし」）。
  • 不一致・チャット未確認のカードは、内容を確かめてカードの確認欄にチェックを入れます。
  • 「確定して保存」を押します。今週の要点・コーションも一緒に保存され、再読込しても消えません。

AI案件の巡回をやり直したときも、2〜4をやり直せば今週の表が新しい内容に直ります。

毎朝に行う操作（月〜金）

1. 朝ブリーフのJSONを作る

プロジェクト「週間タスク」で新しいチャットを作ります。付録Cをコピーして貼り付け、送信します。返ってきた JSON を全部コピーします。

2. 朝ブリーフ画面へ読み込む

画面上部の「朝ブリーフ」タブを押し、「ChatGPT Project の朝ブリーフを読み込む」を開きます。JSONを貼り付けて「読み込む」を押します。

3. 内容を確認して保存する

日付、今日の予定、今日やること、重要な注意、AI案件現在地を確かめて「保存」を押します。保存すると、確認できたAI案件の現在地が今週の表にも入ります（週間タスク画面のカードに「確認済み 日時」と出ます）。

日中にタスクの結果を記録する

朝ブリーフ画面の「今週のタスク」で記録するタスク名を押し、「状態」「曜日」「実施結果」「メモ」「次回申し送り」を入れて「この内容で保存」を押します。週間タスク画面では「✎ 記録」から入力し、「確定して保存」を押します。

AIが拾わなかったタスクを追加する

週間タスク画面で「＋ タスク追加」を押します。タスク名・種別・曜日・優先度・重点・メモを入れて「追加して保存」を押します。

止める条件

  • Workが保存できなかった、またはJSONの作成で資料の取得失敗が出た。
  • 週間タスクJSONの対象週が今週と違う。
  • JSONを「読み込む」で受け付けない、または画面にエラーが出る。
  • 保存後に「保存しました」と出ない。

この場合は保存を繰り返さず、エラーの表示を残して連絡してください。

- （取得に失敗した情報源があれば「取得失敗：情報源名」。なければ「なし」）

保存ルール：
- 保存前に、Google Drive「週間タスクボード」フォルダ直下だけを対象に、ファイル名が完全一致する「朝情報.md」を検索する。
- 「朝情報.md」が1件だけ存在する場合は、その既存ファイルのファイルIDを特定し、その同じファイルIDの内容を今回の朝情報で更新する。別の同名ファイルを新規作成してはいけない。
- 「朝情報.md」が0件の場合だけ、新規作成してよい。
- 「朝情報.md」が2件以上ある場合は、どれかを推測で選ばず保存を中止し、「保存失敗：同名ファイル複数」と報告する。
- 既存ファイルの更新に失敗した場合は、削除・新規作成・別名保存・同名ファイル新規作成で代替せず、「保存失敗」として停止する。
- 保存後に対象ファイルを再取得し、ファイル名、保存先、内容の日付、ファイルIDを確認する。
- 既存ファイルを更新した場合は、保存前後でファイルIDが同一であることを確認する。同一でなければ完了扱いにしない。

ルール：
- 推測で埋めない。判断できない点は「要確認」と書く。
- 保存後、ファイル名・保存先・ファイルID・予定件数・要対応メール件数・保存結果（新規作成／既存ID更新／保存失敗）を報告する。
