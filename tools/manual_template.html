週間タスク・朝ブリーフ ユーザー操作マニュアル

この手順で、週のタスクを確定し、平日の朝ブリーフを確かめます。JSON（週間分析・朝ブリーフ）は自動で作られ、Google Drive「週間タスクボード」直下の 週間分析.json・朝ブリーフ.json に保存され、アプリが1時間おきに自動で取り込みます。あなたが JSON を作る・コピーする・貼る・目で確かめる必要はありません（2026-10-22 から）。予約の本文に使う文は、このページの付録の「コピー」ボタンでコピーしてください（付録の文は、いつも最新のものです）。

毎週月曜に行う操作

1. Web版Workで通常業務を集める

ブラウザで https://chatgpt.com/ を開き、Web版Workを選んで新しいチャットを開きます。付録Aをコピーして貼り付け、送信します。

2. 週間タスク画面で「案」を確かめて保存する

週間タスク画面を開きます。Drive の 週間分析.json の内容が「案」として自動で表示され、画面に「Drive の 週間分析.json（更新日時）を「案」として表示しています」と出ます。

  • 新しいタスクは「候補」として出ます。採用しないカードはゴミ箱で外し、曜日・優先度などは直してかまいません。
  • 今週の表にすでにあるAI案件は「分析結果で更新」と出ます。保存すると、現在地と例外情報が新しい内容に変わります（内容が同じなら「内容に変わりなし」）。
  • 不一致・チャット未確認のカードは、内容を確かめてカードの確認欄にチェックを入れます。
  • 「確定して保存」を押します。今週の要点・コーションも一緒に保存され、再読込しても消えません。確定した週は、案がもう一度出ることはありません（直した内容は上書きされません）。

「確定して保存」を押すまでは、どこにも保存されていません。画面を閉じて開き直すと、案はもう一度最初の内容で表示されます。

毎朝に行う操作（月〜金）

1. 朝ブリーフ画面を開いて見る

画面上部の「朝ブリーフ」タブを押します。今日の朝ブリーフは自動で保存されており、「自動取込：（日時）に Drive の 朝ブリーフ.json から取り込みました」と出ます。確認できたAI案件の現在地も今週の表に入っています（週間タスク画面のカードに「確認済み 日時」と出ます）。

2. 直すときは「今週のタスク」で直す

タスクの状態・曜日・実施結果などは、下の「日中にタスクの結果を記録する」のとおり直します。JSONには触れません。

「自動取込の記録はまだありません」と出たときは、6:45 の予約のあと1時間以内に取り込まれます。しばらくしてから開き直してください。

手動取込（非常用）

自動取込が止まったときだけ使います。ChatGPT のプロジェクト「週間タスク」で、付録B（週間分析）または付録C（朝ブリーフ）を送ると、JSON が Drive のファイルに保存されます。そのファイルの中身を、週間タスク画面の「手動取込（非常用）：分析結果のJSONを貼り付けて読み込む」、または朝ブリーフ画面の「手動取込（非常用）：朝ブリーフのJSONを貼り付けて読み込む」へ貼り付けて「読み込む」を押し、内容を確かめて保存します。

手動で今日の朝ブリーフを保存した日は、あとから届いた 朝ブリーフ.json は取り込まれません（手で保存した内容を上書きしません）。

日中にタスクの結果を記録する

朝ブリーフ画面の「今週のタスク」で記録するタスク名を押し、「状態」「曜日」「実施結果」「メモ」「次回申し送り」を入れて「この内容で保存」を押します。週間タスク画面では「✎ 記録」から入力し、「確定して保存」を押します。

AIが拾わなかったタスクを追加する

週間タスク画面で「＋ タスク追加」を押します。タスク名・種別・曜日・優先度・重点・メモを入れて「追加して保存」を押します。

止める条件

  • 画面に「自動取込できませんでした」「案として表示できません」と赤枠で出た（理由：ファイルがない・日付や対象週が今日・今週ではない・JSONとして読めない・同じ名前のファイルが複数ある・検証に合格しない）。
  • 手動取込（非常用）で、JSONを「読み込む」で受け付けない、または画面にエラーが出る。
  • 保存後に「保存しました」と出ない。

この場合は保存を繰り返さず、エラーの表示を残して連絡してください。
